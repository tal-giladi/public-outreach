# Name, slogan and domain

Checked 19.11.2026 against the .il registry WHOIS (whois.isoc.org.il). "Free" means no registration existed at that moment; it is not reserved for us until bought.

## Recommendation

> **מגיעים בחיים**
> דורשים צעדים. עוקבים אחרי הביצוע.
> **bachaim.org.il**

- The name says the goal in two words and includes everyone: pedestrians, drivers, cyclists.
- `magiim.org.il` and `magiim.co.il` are already taken (private individuals), so the domain uses the second word: **bachaim** ("alive"). Short, easy to say on the radio, and it still reads as the slogan's ending.
- Buy with it: `bechaim.org.il` (common misspelling, redirect) and `bachaim.co.il` (so nobody else takes it). All three were free.
- The site stays on GitHub Pages; only the address changes.

## Alternative: keep the campaign's own name

> **לחזור הביתה**
> **lachzor.org.il**

Your email series is already called "לחזור הביתה", so this gives one name for the series and the site. Weaker for future campaigns that are not about getting home safely.

## How to switch (when you decide; nothing done yet)

1. Buy the domain from an ISOC-accredited registrar ([list](https://en.isoc.org.il/il-cctld/how-to-register-a-domain)). About ₪80–100 a year for .org.il.
2. In the repo's Pages settings, set the custom domain; GitHub adds a `CNAME` file.
3. At the registrar: four `A` records for the bare domain to GitHub Pages' IPs, and a `CNAME` for `www` to `tal-giladi.github.io` ([GitHub docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)).
4. Verify the domain in GitHub (prevents takeover), then turn on "Enforce HTTPS".
5. Old `tal-giladi.github.io/public-outreach/` links redirect automatically.
6. Email on the domain (e.g. `tal@bachaim.org.il`) is a separate setup (Google Workspace or similar).
